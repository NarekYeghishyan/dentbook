## Q2 ✅ Коды ошибок для авторизации и «не найдено»

§7 перечисляет 9 кодов, среди них нет кода для 401/403/404. При этом §2.2 требует, чтобы
доступ к данным чужой клиники давал 404/403, а Шаг 3 вводит вход по JWT — тело ошибки
формата `{ "error": { "code": ..., "message": ... } }` требует кода.

Варианты:

- **A.** Добавить в §7 и `packages/shared/src/errors.ts`: `unauthorized`, `forbidden`,
  `not_found`, `internal_error`.
- **B.** Обходиться существующими (`invalid_key` для публичного API) и отдавать
  404/403 с пустым телом — контракт станет неоднородным.

Рекомендую A. Список кодов — часть публичного контракта, менять его потом дорого.

**Ответ (2026-09-17):** A — добавлены `unauthorized`, `forbidden`, `not_found`, `internal_error` в CLAUDE.md §7 и `packages/shared/src/errors.ts`.
