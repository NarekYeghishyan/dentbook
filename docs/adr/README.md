# Журнал решений (ADR)

Одно решение — один файл `NNNN-краткое-название.md`. Файлы не переписываются:
устаревшее решение помечается `Статус: заменено ADR-NNNN`.

Сюда попадает только то, что не выводится из CLAUDE.md: выбор внутри свободы,
оставленной техзаданием, и компромиссы. Само техзадание не дублируется.

Шаблон:

```markdown
# ADR-NNNN. Название

Дата: YYYY-MM-DD
Статус: принято | заменено ADR-NNNN | отклонено

## Контекст

## Решение

## Последствия
```
