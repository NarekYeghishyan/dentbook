# ADR-0004. Развёртывание на сервер

Дата: 2026-09-17
Статус: принято

## Контекст

Нужен тестовый стенд до готовности VPS клиента. Выбранный стенд — общий сервер с
другими сайтами (nginx + ISPmanager, Ubuntu 18.04, Docker 20.10); системные Node (v10) и
Redis (4.0) для проекта не подходят. CLAUDE.md §10 относит деплой к Шагу 10 и способ не
задаёт. Те же файлы должны подойти для VPS клиента.

Ограничение из ADR-0001: пакеты экспортируют TypeScript-исходники. Собранный
`apps/api/dist/index.js` упадёт, как только импортирует `@dentbook/db`: Node не выполняет
`.ts` с импортами вида `./client.js`.

## Решение

- Всё окружение проекта — в Docker Compose (`deploy/docker-compose.yml`): Postgres 16,
  Redis 7, одноразовый `migrate`, `api`, `worker`. От системных пакетов сервера зависят только
  Docker и nginx.
- Один образ `dentbook-app` на все процессы: полный workspace с devDependencies.
  `drizzle-kit` (миграции) и `tsx` (сиды) — devDependencies.
- `api` и `worker` запускаются через `node --import tsx` из исходников — это обходит
  ограничение ADR-0001 без изменения пакетов.
- Образ собирается на сервере из загруженной рабочей копии (`deploy/deploy.sh`), без
  реестра образов. Тег — короткий SHA коммита, `-dirty` при незакоммиченных изменениях.
- Миграции — сервис `migrate` (`pnpm migrate`); `api` и `worker` стартуют только после его
  успешного завершения (§9: только drizzle-kit).
- Наружу не публикуется ничего, кроме API на `127.0.0.1`. TLS завершает nginx на хосте,
  сертификат — certbot (webroot).
- Лимиты памяти на контейнерах — стенд делит сервер с чужими сайтами.
- Redis с `maxmemory-policy noeviction` — вытеснение ключей ломает очереди BullMQ.

## Последствия

- Стенд поднимается одной командой, соседние сайты и системные пакеты не затрагиваются.
- Образ ~620 МБ: в нём dev-зависимости и фронтенд-инструменты. TODO: перед продом —
  собирать `api`/`worker` в `dist` (или бандлом), отдельный слой без devDependencies,
  миграции — отдельным образом или бандлом; причина отложить — на тесте размер не важен.
- `tsx` в рантайме: транспиляция при старте, ~1 с. TODO: убрать вместе с предыдущим пунктом.
- Сборка на сервере требует доступа к Docker Hub и npm. TODO: реестр образов и CI, когда
  появится VPS клиента и больше одного окружения.
- Compose на серверах с `docker-credential-secretservice` без D-Bus не может скачивать
  образы — `deploy.sh` качает их через `docker pull` и запускает compose с `--pull never`.
