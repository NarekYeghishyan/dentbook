# ADR-0002. Упаковка Mini App и виджета

Дата: 2026-09-17
Статус: принято (Mini App подтверждён заказчиком 2026-09-17, Q3)

## Контекст

1. CLAUDE.md противоречит себе по Mini App: §3 — «отдельная страница, тот же
   Vite-проект», §4 — отдельная папка `apps/miniapp/`.
2. §3 требует собирать виджет в один IIFE-бандл, Шаг 6 ограничивает его 50 КБ gzip.
   Vite в режиме library выносит CSS в отдельный файл — это уже не один бандл.

## Решение

1. Mini App сделан отдельным Vite-приложением `apps/miniapp` (порт 5174), общие типы
   идут через `packages/shared`. Так деплой админки и Mini App независим, а у Mini App
   свой тонкий бандл — он грузится внутри Telegram на мобильном. Вопрос задан
   заказчику (`docs/OPEN-QUESTIONS.md`, Q3); если ответ будет «один проект», переделка
   до Шага 7 дешёвая.
2. Стили виджета живут в TypeScript как строка-шаблон, `.css`-файлов в `apps/widget` нет.
   Это единственный способ получить ровно один файл без дополнительных плагинов.
   Контроль размера — `pnpm --filter @dentbook/widget size`.

## Последствия

- `apps/admin` и `apps/miniapp` дублируют конфигурацию Vite и часть зависимостей.
  Терпимо: два файла по 10 строк против общего конфига, который пришлось бы
  параметризовать.
- Автодополнение и линт CSS в виджете не работают — стили внутри строки.
