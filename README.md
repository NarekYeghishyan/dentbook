# DentBook

Multi-tenant SaaS booking platform for dental clinics. A clinic registers, adds dentists,
services and working hours, gets an API key and embeds the booking form on its own site.
Dentists work through Telegram. Full requirements and invariants live in [CLAUDE.md](CLAUDE.md) —
read it before changing anything.

## Status

Scaffolding only. Step 1 of 10 is in progress: the reference schema ([schema.sql](schema.sql))
is drafted and awaits review before it is ported to Drizzle (see
[docs/OPEN-QUESTIONS.md](docs/OPEN-QUESTIONS.md), Q9). No application code yet.
Current state per step: [docs/PROGRESS.md](docs/PROGRESS.md).

## Layout

```
apps/
  api/        Fastify: public API, admin API, Telegram webhook
  worker/     BullMQ: notifications, reminders, hold cleanup
  admin/      React SPA — clinic panel
  widget/     embeddable booking form (single IIFE bundle)
  miniapp/    Telegram Mini App — dentist schedule
packages/
  db/         Drizzle schema, migrations, seeds
  core/       availability engine, pure functions, no I/O
  shared/     types, error codes, zod validators
docs/         progress tracker, open questions, decision log (ADR)
```

## Getting started

Requires Node 22 LTS (>=22), pnpm 11, Docker.

```bash
pnpm install
cp .env.example .env     # fill in the values
pnpm db:up               # Postgres 16 + Redis 7 via docker compose
pnpm migrate             # available once Step 1 lands
pnpm seed
```

## Scripts

| Command                                  | What it does                               |
| ---------------------------------------- | ------------------------------------------ |
| `pnpm dev`                               | all apps in watch mode                     |
| `pnpm build`                             | build every workspace package              |
| `pnpm lint`                              | ESLint + Prettier check                    |
| `pnpm typecheck`                         | `tsc -b` across the workspace              |
| `pnpm test`                              | Vitest (unit + Testcontainers integration) |
| `pnpm test:coverage`                     | coverage report                            |
| `pnpm migrate` / `pnpm migrate:generate` | apply / generate Drizzle migrations        |
| `pnpm seed`                              | seed demo data                             |
| `pnpm db:up` / `pnpm db:down`            | start / stop Postgres and Redis            |

`pnpm lint && pnpm test` must pass before a step is marked done (CLAUDE.md §10).
